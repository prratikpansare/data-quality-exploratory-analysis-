# Data Quality and Exploratory Analysis

## Project Overview
This project focuses on checking data quality,
cleaning a dataset, and performing Exploratory
Data Analysis (EDA) using Python.

## Objectives
- Identify missing values.
- Detect duplicate records.
- Clean and prepare the dataset.
- Calculate statistical summaries.
- Visualize student performance.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Features
1. Data quality assessment
2. Missing value handling
3. Duplicate record removal
4. Statistical analysis
5. Data visualization

## Installation
Install the required libraries:

```bash
pip install pandas matplotlib
```

## How to Run
Run the following command:

```bash
python data_analysis.py
```

## Output
- Original dataset
- Missing value report
- Duplicate record count
- Cleaned dataset
- Statistical summary
- Student performance bar chart

## Conclusion
This project demonstrates how Python can be used
to improve data quality and understand datasets
through exploratory data analysis.
